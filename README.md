发票解析接口支持上传自定义格式定义，攻击者在里面声明了一个外部实体，服务器上的文件就被读进了响应：必须禁用外部实体与外部格式定义；内部实体数量与展开深度必须有上限；实体不得引用网络资源；解析失败必须整体拒绝；只允许白名单内的元素；处理指令必须忽略；批量解析各文档独立。不变量：任何文档都读不到本地文件或网络；同一文档两次解析结果相同。

接口契约

策略是字典，包含 allow_external_entities、allow_external_dtd、max_entities、max_entity_depth 与 allowed_elements。前两个键的值必须为 False，两个上限必须为正整数，元素白名单必须非空。

解析成功返回根元素。扫描格式定义返回描述外部标识与内部实体的字典。实体检查与元素检查返回问题列表，空列表表示通过。策略检查返回问题列表。批量解析返回 results 与 errors 两个并行列表，单个文档失败只影响自己的位置。

所有校验失败都以 ValueError 子类抛出，不返回部分结果。解析不读取本地文件，不访问网络。
